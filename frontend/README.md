*FitFlow Frontend

This folder is reserved for the React Native frontend of the FitFlow redesign.

Planned Technology

-React Native
-JavaScript/TypeScript
-iOS and Android support
-Optional lightweight web dashboard

*Main Responsibilities

The frontend will provide the user interface for:

-Home dashboard
-AI workout planner
-Nutrition logging
-Progress tracking
-Community and social features

The frontend will communicate with the NestJS backend API and Firebase services according to the proposed architecture.

*FitFlow Backend

This folder is reserved for the NestJS backend API of the FitFlow redesign.

*Planned Technology

-Node.js
-NestJS
-REST API
-PostgreSQL
-Firebase Authentication integration

*Main Responsibilities

The backend will handle:

-User data
-Workout plans
-Workout history
-Nutrition records
-Trainer-client relationships
-Authentication token verification
-Communication with the AI microservice
-Core business logic
